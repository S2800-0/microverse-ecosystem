# Contributing

Thanks for your interest in Microverse Ecosystem.

1. Open an issue first for anything larger than a small fix.
2. Work on a feature branch.
3. Run `npm test` with Node.js 24 or newer. It should pass before you open a pull request.
4. Add a test when you change behaviour.

Please keep the library free of runtime dependencies, and don't add model keys, personal data, or images you don't have the rights to share.

By contributing, you agree that your contribution is released under the [MIT License](LICENSE).
